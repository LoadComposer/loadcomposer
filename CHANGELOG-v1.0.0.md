# LoadComposer v1.0.0 change summary

Date: 2026-08-08

`v1.0.0` is the first stable release of LoadComposer. It is a controlled,
version-only promotion of the published and operationally tested
`v1.0.0-rc.4` candidate.

The promotion changes current version metadata, versioned filenames,
Cache-Control paths, release tests and release documentation. It regenerates
the standalone package, sidecars, test bundle, manifest and checksum list.

It does not change application behavior, algorithms, geometry, coordinates,
results, equipment data, pallet presets, trailer prudential thresholds, UI,
themes, responsive behavior, printing, operational translations, legal terms,
the 404 page, or the inline LICENSE/NOTICE behavior.

The stable label is not a certification. LoadComposer remains an
heuristic geometric planning aid and does not verify weight, payload, axles,
balance, securing, legal compliance, or physical loadability.
