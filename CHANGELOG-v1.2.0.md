# LoadComposer v1.2.0

Release date: 2026-08-12.

## Included

- A real localized `/downloads/` page with the online planner as the clear
  recommendation whenever Internet access is available.
- Offline HTML and ZIP choices for computers that have no Internet access or
  must remain offline, with deterministic SHA-256 values.
- Clearer “Remaining space” terminology in the results and print output.
- A simpler compact-loading instruction that states only the free length.
- Side loading recorded as a future roadmap item, not implemented.

## Not changed

No loading algorithm, geometry, coordinate, capacity, vehicle, pallet,
threshold, warning condition, weight, balance, axle-load, or access-direction
model is changed. The offline planner remains self-contained and makes no
automatic remote request.
