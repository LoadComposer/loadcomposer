Versione offline

PER COMPUTER SENZA INTERNET

Pensata per computer che non hanno accesso a Internet o devono restare offline. È una semplice pagina web standalone e il planner funziona senza connessione. Non si aggiorna automaticamente: per usare nuove funzioni e correzioni devi sostituire manualmente il file con una versione più recente.

Se hai accesso a Internet, normalmente non serve scaricare questa versione.
