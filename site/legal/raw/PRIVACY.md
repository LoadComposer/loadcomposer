# Privacy

LoadComposer performs its application calculations locally in the browser. The official application has no application backend, account system, tracker, analytics script, advertising script, remote font, or telemetry endpoint.

## Data handled by the application

Dimensions, quantities, selections, and other planning inputs remain in the active browser context. The application does not intentionally transmit them to the project owner. Printing, saving a page, browser extensions, device synchronization, or other user-controlled browser features may create copies outside the application.

The selected theme and language preference may be stored in browser `localStorage` under LoadComposer-specific keys. Clearing site data removes those preferences. The standalone file uses the same local browser mechanism where the browser permits it.

## Hosting logs

The hosting provider, network operator, content-delivery network, browser, or organization managing a deployment may process ordinary technical logs such as IP address, timestamp, URL, user agent, response status, and security events. Those logs are outside the application runtime and are governed by the operator’s configuration and privacy terms. A third party that hosts a copy is responsible for its own notices and legal compliance.

## External links

Following the GitHub link leaves the application and is governed by the destination service. LoadComposer does not load GitHub resources until the user follows the link.
