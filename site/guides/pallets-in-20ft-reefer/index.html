How many pallets fit in a 20 ft reefer container?

Using LoadComposer's current 20' Reefer reference, the planner finds 10 Euro pallet floor positions, 9 industrial pallet positions, or 9 North American pallet positions with rotation allowed, zero modeled clearance, and no stacking.

This result uses LoadComposer's nominal refrigerated-container data. It does not imply that every 20-foot reefer has identical usable dimensions. Insulation, refrigeration equipment, floor profile, manufacturer, series, condition, and required airflow can all change the real loading envelope.

The planner calculates with the displayed reference values; the actual unit still needs to be checked.
