# LoadComposer v1.5.0 test bundle

This bundle contains the v1.5.0 source, offline standalone, build scripts, tests, and current versioned QA results. It also preserves the byte-identical `loadcomposer-v1.4.0-test-bundle.zip` as the historical QA archive. The Advanced Stacking solver is in `site/advanced-stacking-engine.js`; the independent validator is in `site/advanced-stacking-validator.js`. ## Historical C2 performance and computation evidence (15 October 2026)

The current application uses versioned Blob Worker jobs for larger inputs, with
main-thread production validation and an explicit compatibility fallback. The
static Worker program is generated by `scripts/build-computation-v1.5.0.mjs`;
`npm run build` regenerates both online and offline forms. No eval or network
worker import is used. The original synchronous geometry producers remain for
the small-input path and direct regression checks.

Run `npm run test:c2-computation` for real Chromium HTTP/CSP and file-offline
Worker, fallback, cancellation, reset, corrupted replies, stale print, 500/501
admission and locale coverage. It is included in the normal `npm test` chain.
See `performance-c2-v1.5.0/README.md` for source delta, admitted C1b baseline,
new comparative campaigns, raw repeated benchmarks and reproduction commands.
The separate `PERFORMANCE_C2-v1.5.0.md`, final report and package verification
state current outcomes. Older hotfix/C1/C1b reports remain historical evidence.
C1A1626 is a newly proved pre-existing floor-quality gap (both C1b/C2 10/7,
exact oracle 10/8), preserved explicitly for C3. C3 independent audit and C4
certification remain open; no publication or deployment is implied.
